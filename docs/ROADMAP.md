# Development Roadmap — Deen App

High-level milestones and vision for Deen App's evolution.

---

## Vision Statement

Create the **world's most respectful Islamic companion app** — privacy-first, ad-free, and engineered specifically to protect congregational focus during prayer.

---

## Milestones

### Milestone 1: Core Foundation (✅ Completed)
- Prayer time calculations with configurable silent windows
- Bilingual UI (Bangla default for Bangladesh, English fallback)
- Location auto-detection
- Clean, modern Islamic UI with emerald/gold design system
- Three-tab navigation: Dashboard, Silent Settings, Settings

**Deliverables:** Functional React Native app with web preview

---

### Milestone 2: Native Android Silent Mode (Next Priority 🎯)
- Integrate Android Do Not Disturb (DND) permission
- Background task scheduling for silent mode triggers
- Pre-silent push notifications (e.g., "Phone will be silenced in 5 minutes for Asr")
- Auto-restore original volume after prayer duration

**Target:** Alpha release to internal testers

---

### Milestone 3: Polish & Islamic Lifestyle Features
- Dark theme support
- Hijri (Islamic) calendar date display
- District-wise calculation adjustments for Bangladesh
- Next prayer countdown timer with live ticking seconds

**Target:** Beta release on Google Play Console (internal testing track)

---

### Milestone 4: Global Expansion
- Support for additional calculation methods (ISNA, Muslim World League, Umm al-Qura)
- Qibla compass direction
- Multi-language support: Arabic, Urdu, Hindi
- Ramadan mode (Sehri/Iftar alerts)

**Target:** Public release on Google Play Store

---

### Milestone 5: Community & Ecosystem
- User feedback loop and rating optimization
- Accessibility audit (WCAG AA compliance)
- Documentation for contributors
- Open-source components (with Islamic licensing considerations)

**Target:** Version 1.0.0 stable release
